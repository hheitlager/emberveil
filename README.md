## Welcome to Emberveil

Emberveil is a personal development and customization project focused on making everyday desktop experiences more useful, consistent, and enjoyable.

The collection brings together lightweight utilities, interface enhancements, and visual customization projects for Windows and Linux.

The goal is simple: create desktop experiences that feel cohesive, work naturally, and offer meaningful customization without unnecessary complexity.

## Projects

### Windhawk Mods

A growing collection of Windows taskbar enhancements and desktop utilities built for [Windhawk](https://windhawk.net/).

|Project|Description|Status|
|---|---|---|
|[**Mawaqit**](https://github.com/hheitlager/windhawk-mawaqit)|Prayer times and countdowns integrated into the Windows taskbar.|Published|
|[**Virtual Desktop Manager**](https://github.com/hheitlager/virtual-desktop-manager)|Customizable virtual desktop indicators and navigation for the Windows taskbar.|In development|
|[**Simple System Resources**](https://github.com/hheitlager/simple-system-resources)|Lightweight taskbar resource monitoring with visual indicators and detailed flyouts.|Experimental|
|[**Tray Overflow Sort**](https://github.com/hheitlager/tray-overflow-sort)|An experiment in organizing the Windows system tray overflow area.|Experimental|

Each mod is maintained in its own repository, with independent development, documentation, and release history.

### Windhawk Configurations

Alongside the custom mods, Emberveil includes a collection of Windows desktop styling presets.

[**Explore Windhawk Configurations**](https://github.com/hheitlager/windhawk-configurations)

The collection includes taskbar, clock, Start menu, notification center, and Mawaqit configurations, with Emberveil and Catppuccin-inspired designs and supporting image assets.

These presets are intended as starting points for building a cohesive Windows desktop. Some configurations require additional assets or adjustments to local file paths.

## Design Philosophy

Emberveil projects follow a few simple principles:

- **Keep things lightweight.** Focus on a specific purpose without unnecessary complexity.
    
- **Make customization meaningful.** Offer flexibility without making everyday configuration difficult.
    
- **Respect the desktop.** Integrate naturally with the existing operating system and its interface.
    
- **Balance form and function.** Visual consistency should improve usability, not compromise it.
    
- **Build iteratively.** Experiment, test, refine, and publish when a feature is ready.
    

## Beyond Windhawk

Emberveil is not limited to Windows or Windhawk.

Future additions may include desktop themes, Linux customization, configuration collections, and small utilities.

The intention is to maintain a shared visual identity while allowing individual projects to evolve independently.

## Development and Releases

Projects may contain experimental features, development builds, or unfinished functionality.

A public GitHub repository does not necessarily indicate that a mod has been released through the Windhawk store. Check each project's repository for its current status and installation instructions.

Development snapshots and experimental features are not necessarily approved releases.
